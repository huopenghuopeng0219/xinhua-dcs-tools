# 新华DCS辅助器 V2.2.2

本项目从旧版接线表生成器复制代码后独立开发。旧项目目录只作为依赖读取，不在其中生成或修改文件。所有输出保存在**本项目目录**。

## 启动

直接运行 `dist/新华DCS辅助器.exe`。开发环境也可以运行 `接线总表生成器_窗口.py`。

## 功能

1. **生成接线总表**：选择机柜设计 Excel，从 `-AZ` 和卡件排布表生成 `.xlsx`。
2. **生成转组态**：选择接线总表，生成 `.xls`。
3. **生成差异表**：选择机柜设计 `.xls`、`.xlsx` 或 `.xlsm`，读取名称以 `-MX` 结尾的工作表，从斜体“整件”行之后统计有代号的物料。
4. 三种输出文件都保留源文件中的项目编号、项目名称和版本，只替换功能名称，例如 `项目-机柜设计-V0.xlsx` 生成 `项目-接线总表-V0.xlsx`。
5. 差异表按代号汇总数量；同一代号有不同名称时，采用第一次出现的名称。工作表名为“机柜差异表”。
6. 第一行显示项目差异表标题；表格从 A 列开始，序号 1 直接对应第一种物料，不保留“整件”、签字栏或其他无代号内容。
7. “备注”列改为“合同数量”并留空；“更改”列改为“数量差异”，待填写合同数量后按 `数量-合同数量` 计算；“原因”列按每两行纵向合并。工作表以普通视图打开，并对整个表格使用细线“所有线框”。

示例命令行：

```powershell
python material_difference.py "机柜设计文件.xls"
```

示例检查：

```powershell
python test_material_difference.py
```

差异表沿用示例 `-MX` 表的表头和物料格式，并删除模板中未使用的前五列。
