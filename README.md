# 接线总表生成工具

这个Python脚本用于生成和填充Excel格式的接线总表，是对原VBA代码的转换实现。

## 功能说明

该脚本能够：
1. 通过文件选择对话框让用户选择源Excel文件
2. 创建新的"接线总表"工作表
3. 自动遍历所有以"-az"结尾的工作表
4. 从这些工作表中提取相关数据并填充到接线总表中
5. 设置表格格式、条件格式和边框
6. 支持不同信号类型（DI、DO、SOE、AI、AO、PI、RTD、TC）的处理
7. 在源文件同目录下保存生成的接线总表
8. 提供友好的错误处理和提示信息

## 依赖库

该脚本需要以下Python库：
- `openpyxl` - 用于操作Excel文件
- `tkinter` - 用于显示文件选择对话框和消息框（Python标准库，无需额外安装）

## 安装依赖

在运行脚本前，请先安装所需的依赖库：

```bash
pip install openpyxl
```

## 使用方法

1. 将`generate_wiring_table.py`文件保存到您的计算机上
2. 确保已安装所需的依赖库
3. 运行脚本：
   
   ```bash
   python generate_wiring_table.py
   ```
4. 在弹出的文件选择对话框中，选择包含"-az"工作表的源Excel文件
5. 脚本将在源文件同目录下生成一个名为`接线总表.xlsx`的Excel文件
6. 如果目标文件已存在，系统会询问是否覆盖

## 代码结构说明

- `ExcelHelper`类：提供对Excel文件的基本操作功能
- `WiringTableGenerator`类：实现接线总表的生成和填充逻辑
- `main()`函数：程序入口，创建实例并调用相应方法，处理文件选择和保存逻辑

## 主要函数说明

1. `generate_and_fill_wiring_table()` - 生成并填充接线总表的主函数
2. `generate_wiring_table_header()` - 创建接线总表的表头
3. `set_table_format()` - 设置表格的格式和条件格式
4. `get_fill_rows_and_type()` - 获取填充行数和信号类型
5. `get_h_column_value()` - 获取H列（测点类型）的值
6. `get_front_back()` - 获取正反面信息
7. `is_dotk_match()` - 检查是否匹配DOTK条件
8. `get_first_two_chars()` - 获取合并区域中第一个非空单元格值的前两个字符

## 错误处理

脚本包含了基本的错误处理机制，可以捕获并显示常见的错误情况，如：
- 未选择源文件
- 源文件格式不正确
- 文件访问权限问题
- Excel文件处理错误

## 注意事项

1. 确保源Excel文件包含以"-az"结尾的工作表
2. 运行脚本前请确保您有足够的权限读取和写入文件
3. 如果生成的接线总表为空，请检查源文件中的"-az"工作表是否包含有效数据
